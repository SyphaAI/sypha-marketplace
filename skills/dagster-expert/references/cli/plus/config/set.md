---
title: dg plus config set
triggers:
  - "set Dagster Plus CLI configuration values"
---

Configure values for the Dagster Plus CLI.

```bash
dg plus config set <KEY> <VALUE>
```

Supported keys:

- `api-token` — specify the API token used for authentication
- `org` — specify the organization name
- `deployment` — specify the default deployment name
- `url` — specify the Dagster Plus URL
- `region` — specify the region (`us` or `eu`)
