# Fallback Design Tokens Pointer

The authoritative fallback token reference is located at `references/tableau-design-tokens.md`.

Treat that file as the single source of truth for:
- default typography
- default colors
- default dashboard sizing
- default container hierarchy
- default Tableau fidelity constraints

Whenever Step 0 relies on fallback values, the generated `design-tokens.md` must declare each one under `## Fallback Decisions`.
