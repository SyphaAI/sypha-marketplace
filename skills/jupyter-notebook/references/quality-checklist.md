# Quality Checklist

Before handing off a notebook:

- Execute it from top to bottom at least once (or to the maximum extent the environment permits).
- Verify that early cells establish all required state; eliminate hidden dependencies on prior run state.
- Keep outputs clean. Do not produce large outputs when a brief summary conveys the same information.
- Prefer compact tables, key metrics, or short printouts.
- Make the narrative easy to skim. Use headings and concise bullets; avoid lengthy paragraphs.
- Include TODOs only when genuinely necessary, and mark them clearly.
- If execution cannot be performed, explain the risk explicitly and describe how to validate the notebook locally.
