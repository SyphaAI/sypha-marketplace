# duckdb

## Installing the Driver

To install the DuckDB ADBC driver using dbc, run:

```sh
dbc install duckdb
```

## Connecting

To connect, set either the `uri` or `path` option (e.g., `db.duckdb`), or leave both unset for an in-memory database.

## More Information

Additional options are documented at https://duckdb.org/docs/stable/clients/adbc#python.
